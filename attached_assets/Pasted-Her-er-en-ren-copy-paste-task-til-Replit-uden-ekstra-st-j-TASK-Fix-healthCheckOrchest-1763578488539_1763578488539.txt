### 3.2. Tilføj intern validator (policy-type sanity check)

Implementér en helper i samme fil eller et lille utils-modul, fx:

```ts
function guessPolicyTypeFromCoverages(
  whatsIncluded: Array<{ coverage?: string }>
): 'hus' | 'indbo' | 'ulykke' | 'unknown' {
  const names = (whatsIncluded ?? [])
    .map(c => (c.coverage || '').toLowerCase());

  const has = (s: string) => names.some(n => n.includes(s));

  if (has('invaliditet') || has('dødsfald') || has('tandskade')) return 'ulykke';
  if (has('indbo') || has('cykel') || has('retshjælp')) return 'indbo';
  if (has('bygningsbrand') || has('bygningsbeskadigelse') || has('fritidshus')) return 'hus';

  return 'unknown';
}
```

Efter AI-kaldet i orchestratoren:

```ts

if (guessed !== 'unknown' && guessed !== snapshot.policy_type) {
  logger.warn(

  );

  // For now (for test user / dev):
  // either:
  // 1) throw new Error(...) to fail fast
  // or
  // 2) skip insertHealthCheck for this snapshot

  // IMPORTANT: we must NOT write mismatched health_checks to DB.
}
```

I prod kan vi nøjes med at logge en WARN, men til at starte med er det OK at være aggressiv (hellere ingen health_check end en forkert).
