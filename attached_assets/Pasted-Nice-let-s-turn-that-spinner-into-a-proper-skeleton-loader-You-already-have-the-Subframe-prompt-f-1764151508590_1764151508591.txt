## 1. Small fix for your skeleton code

Tailwind doesn’t understand `@keyframes pulse` inside `className`, so that string should not be there. You only need `animate-pulse`.

So in your TSX, **everywhere** you have:

```tsx
className="... bg-neutral-200 @keyframes pulse animate-pulse"
```

tell Replit to make it:

```tsx
className="... bg-neutral-200 animate-pulse"
```

Same for other variants like `rounded-full bg-neutral-200 @keyframes pulse animate-pulse` → `rounded-full bg-neutral-200 animate-pulse`.

You can let Replit handle that via the prompt (see below), instead of manually fixing all occurrences.
