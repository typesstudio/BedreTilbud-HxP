- Find tekst som: 
  - “Årlig pris inklusiv ... er 8.734,59 kr.”

  - sourceTable = "dækning-selvrisiko".
- Hvis selvrisikoen står på to linjer, skal de flettes:

- Brug tabellen “Forsikringssummer for de valgte dækninger” til at udfylde limit hvor muligt.

5) additionalCoverages
- Brug:

- Opret en entry per tilvalg:
  - name = dækningsnavn (fx "Udvidet vand").
  - limit = null hvis ingen tydelig sum.
  - deductible = null hvis ikke nævnt specifikt i policen.
  - included = true (tilbuddet indeholder dækningen) – eller false, hvis det tydeligt står at den IKKE er valgt.

6) Bevar rå tekstformatering
- I name: fjern kun overflødige linebreaks/spaces.
- I limit og deductible: kopier tallet og “kr” nøjagtigt, fx:
  - "2.834 kr .” → "2.834 kr"
  - "10.000 .000 kr." → "10.000.000 kr"

ALGORTIME – FØLGES I DENNE RÆKKEFØLGE:

STEP 1 – SAMLE ALLE DÆKNINGER
- Lav en intern liste over alle coverages = mainCoverages + additionalCoverages.
- AntalAll = antal mainCoverages + antal additionalCoverages.

STEP 2 – BYG whatsIncluded 1:1
- For HVER coverage i denne liste skal du lave PRÆCIS én entry i whatsIncluded.

Mapping:

coverage.name           → whatsIncluded[].coverage (kort label, maks 4–5 ord)
coverage.limit          → whatsIncluded[].attributes.sum
coverage.deductible     → whatsIncluded[].attributes.selvrisiko (se regler nedenfor)
coverage.included true  → value = "inkluderet"
coverage.included false → value = "ikke inkluderet"
coverage.included null  → value = "ukendt"

Hvis coverage.limit er null → attributes.sum = null

STEP 3 – SELVRISIKO (KRITISK FELT)

- Hvis coverage.deductible ER IKKE null:
  - attributes.selvrisiko MÅ ALDRIG være null.
  - Kopiér værdien 1:1 som tekst (inkl. punktummer, procent, "kr").
  - Eksempler:
    - "2.834 kr" → "2.834 kr"
    - "5.000 kr" → "5.000 kr"
    - "10% (min. 2.500 kr)" → "10% (min. 2.500 kr)"
- Hvis coverage.deductible er null:
  - attributes.selvrisiko = null.

STEP 4 – STATUS / VARIANT

- status beskriver om dækningen ser stærk, neutral eller svag ud ud fra selvrisiko og type.

Regler:
- Hvis coverage.included = false → status = "warning".
- Ellers vurder på selvrisiko:
  - selvrisiko ≤ 2.500 kr → status = "success"
  - 2.500 < selvrisiko < 5.000 kr → status = "warning"
  - selvrisiko ≥ 5.000 kr → status = "error"
  - ukendt selvrisiko → status = "neutral"

Hvis selvrisiko er tekst med procent → vurder groft:
  - fx "10% (min. 2.500 kr)" → status = "warning" (måske dyrt).

STEP 5 – ATTRIBUTES ØVRIGE FELTER

For hver whatsIncluded-entry:

{
  "coverage": "...",
  "description": "kort dansk forklaring af, hvad dækningen gør",
  "value": "inkluderet" | "ikke inkluderet" | "ukendt",
  "status": "success" | "neutral" | "warning" | "error",

  }
}
