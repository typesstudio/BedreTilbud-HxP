id

status (pending, sent, responding, completed)

Key endpoints

POST /api/onboarding/start

Body: { email }

Creates onboarding_sessions row if none open for that email

Returns: { onboardingSessionId, currentStep }

POST /api/onboarding/upload

Auth: onboardingSessionId (and CSRF / signed token)

Body: files

Stores files in storage, creates insurance_policies

Kicks off OCR/health-check pipeline asynchronously

Returns updated session: { onboardingSessionId, policyIds }

POST /api/onboarding/info

Body: { onboardingSessionId, fullName, cpr, preference }

Updates session (and optionally profiles if user exists)

POST /api/onboarding/companies

Body: { onboardingSessionId, selectedCompanyIds }

Creates company_requests rows

Marks onboarding_sessions.status = 'completed'

If user_id is null:

Trigger sign-up / magic-link flow, embedding onboardingSessionId in redirect URL param

POST /api/onboarding/attach-user (called when magic link is used)

Body: { onboardingSessionId }

Uses authenticated Supabase user.id

Writes user_id into:

onboarding_sessions

insurance_policies for that session

company_requests for that session

Copies info into profiles if empty

POST /webhooks/health-check (already existing from your other tickets)

Payload: { onboardingSessionId, policyIds }

n8n/Eden/Mistral does:

OCR → JSON → health check per policy

Updates insurance_policies.ocr_json_url + .health_check_json

Updates onboarding_sessions.health_check_status = 'done'

4. Automatic health check after signup

When does the health check start?

Best setup:

Trigger 1: Immediately after each successful upload in Step 2:

Frontend: nothing extra

Backend:

POST /webhooks/health-check (with onboardingSessionId & policyIds)

Status → onboarding_sessions.health_check_status = 'running'

Trigger 2 (safety): When onboarding is completed (after companies selected)

If health_check_status = 'not_started', trigger pipeline again (fallback)

Pipeline behaviour (n8n / backend services)

Receive webhook with onboardingSessionId

Fetch insurance_policies for that session with ocr_status = 'not_started'

For each file:

Run OCR (Eden/Mistral)

Save JSON to storage (ocr_json_url)

Run HealthCheckService to calculate:

Total årlig præmie

Mulige besparelser (benchmarked vs. market)

Highlights, strengths/weaknesses

Store result in insurance_policies.health_check_json

When all policies done:

Set onboarding_sessions.health_check_status = 'done'

Link to user profile

When the user eventually verifies their email / logs in:

attach-user endpoint (above) links:

onboarding_session → user_id

All insurance_policies & company_requests → user_id

Health check is already calculated; the dashboard just reads health_check_json for the user’s policies.
