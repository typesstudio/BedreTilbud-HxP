**Replit prompt – Ticket A: DB & pipeline (precomputed JSON)**

You are working on a TypeScript/React + Node backend project called **BedreTilbud**.
It’s an insurance app that does AI-based **health checks** and **comparisons** of insurance policies.

We’re now implementing **Ticket A – DB & pipeline**:

> Add persistent JSON columns for health checks and comparisons, and wire the code so these are used as the single source of truth.
> (No API handlers should call AI or recompute these on request – that will be handled by external flows like n8n / AI agents.)

1. **Database**

   * Add a `jsonb` column `health_check_json` to the table that represents **policy snapshots** (user’s current insurances and incoming offers).
   * Add a `jsonb` column `comparison_json` to the table that represents **per-policy comparisons** (current vs offer).

2. **Pipeline hooks**

   * Identify where **health check JSON** and **comparison JSON** are currently produced in the code (if at all).
   * If they are produced outside this repo (e.g. n8n), create **clear integration points**:

     * A helper function or a minimal webhook endpoint to update these new columns, **or**
     * A documented SQL update that can be called from n8n / Supabase node.

3. **Do NOT change behavior for the frontend yet**

   * Ticket A is only about DB & pipeline.
   * Do **not** refactor the frontend queries or the read endpoints here (that’s later tickets).

## Step 5 – Add minimal integration points (webhooks or helpers)

### Option A – Webhook endpoints (recommended if the backend already exposes APIs to n8n)

If the backend already has an API router (e.g., `server/routes.ts` or `server/api/*.ts`), add:

1. A POST endpoint to save health check JSON:

   ```ts
   app.post("/api/webhooks/health-check", async (req, res) => {
     // expected payload:
     // { policySnapshotId: string, healthCheckJson: HealthCheckJson }
     const { policySnapshotId, healthCheckJson } = req.body;

     if (!policySnapshotId || !healthCheckJson) {
       return res.status(400).json({ error: "Missing payload" });
     }

     await db
       .update(policySnapshots)
       .set({ healthCheckJson })
       .where(eq(policySnapshots.id, policySnapshotId));

     return res.json({ ok: true });
   });
   ```

2. A POST endpoint to save comparison JSON:

   ```ts
   app.post("/api/webhooks/comparison", async (req, res) => {
     // expected payload:
     // { comparisonPairId: string, comparisonJson: ComparisonJson }
     const { comparisonPairId, comparisonJson } = req.body;

     if (!comparisonPairId || !comparisonJson) {
       return res.status(400).json({ error: "Missing payload" });
     }

     await db
       .update(comparisonPairs)
       .set({ comparisonJson })
       .where(eq(comparisonPairs.id, comparisonPairId));

     return res.json({ ok: true });
   });
   ```

* Make sure body parsing (JSON middleware) is already in place; if not, add it.
* Do **not** add any AI logic here. These endpoints simply **persist** JSON.
