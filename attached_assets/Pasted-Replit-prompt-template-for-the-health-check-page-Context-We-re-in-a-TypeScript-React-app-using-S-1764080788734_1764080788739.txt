Replit prompt template (for the health-check page)

Context

We’re in a TypeScript React app using Subframe components (@/ui/components/*) and DefaultPageLayout.

There is a health-check page for the route /sundhedstjek/:snapshotId. This page currently renders a very basic layout and doesn’t match the Subframe design.

There is a hook usePolicyHealthCheck(snapshotId) and a transformer transformHealthCheck.ts that returns a ViewModel. The page should only use that ViewModel, no direct raw JSON access and no hardcoded numbers.

We already have comparison components such as:

ComparisonHeader / comparison layout for the offer comparison pages

ComparisonSavingsChart (AreaChart wrapper)

ComparisonDetailedMatrix or similar coverage components
Reuse these where it makes sense so that changes to components are reflected across both comparison and health-check layouts.

Goal

Implement the health-check page UI so it matches the Subframe design for “Dit forsikringstjek” as closely as possible.

All content must come from the health-check ViewModel returned by transformHealthCheck.ts.

No static numbers or labels other than section headings like “Hvad er inkluderet”, “Dine forsikringsfordele”, etc.

STEP 1: Confirm and tidy the data layer

Open client/src/utils/transformHealthCheck.ts and:

Define/confirm a clear exported TypeScript type, e.g. HealthCheckViewModel.

Make sure it contains at least:

overall: yearlyPotentialSavings, yearlySavingsPercent, currentAnnualPremium, offerAnnualPremium, chartTotals (monthly, 12m, 10y).

benefits: array of { id, title, description, iconVariant }.

coverages: array of { id, label, description, value, variant } for the “Hvad er inkluderet” table.

strengths and weaknesses: arrays for the “Styrker & svagheder” two-column grid.

savingsOverTime: array { monthIndex, label, cumulativeSavings } for the chart.
