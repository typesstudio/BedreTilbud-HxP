Yes, it’s absolutely possible – and you **don’t need new backend fields** to do it 🎯

You already have, per policy in `policyComparisons`:

* `currentAnnual` (current price)
* `offerAnnual` (offer price)
* `annualSavings` (difference)

From that we can **derive a savings line for each policy**:

* Monthly saving for that policy: `annualSavings / 12`
* Cumulative over 10 years (120 months): `monthIndex * monthlySaving`

So you can:

* Show **all policy types as separate series** in the Subframe `AreaChart`
* Use the existing **top tabs** (Samlet / Indbo / Hus / …) to switch between:

  * **Samlet** → all series at once (Indbo, Hus, Ulykke…)
  * A specific tab → only that policy’s line
* Keep everything dynamic: if later you add “Bil” or “Rejse”, they just show up as extra series.

---

### Concrete structure I’d recommend

In your comparison view-model (`transformComparison.ts`):

```ts
export interface SavingsSeriesView {
  key: string;          // "indbo", "hus", "ulykke"
  label: string;        // "Indbo", "Hus", "Ulykke"
  annualSavings: number;
  monthlySavings: number;
  tenYearSavings: number;
  // 120 points, one per month, cumulative
  points: { month: number; cumulative: number }[];
}

export interface SavingsOverTimeView {
  totalAnnualSavings: number;           // sum of all
  totalTenYearSavings: number;          // sum(series.tenYearSavings)
  series: SavingsSeriesView[];          // one per policy type
}
```

Derive it purely on the frontend from `policyComparisons`:

```ts
const policies = comparisonJson.policyComparisons ?? [];

const series: SavingsSeriesView[] = policies.map((p) => {
  const annual = p.annualSavings ?? (p.currentAnnual - p.offerAnnual);
  const monthly = annual / 12;
  const tenYear = annual * 10;

  const points = Array.from({ length: 120 }, (_, i) => {
    const month = i + 1;
    return { month, cumulative: monthly * month };
  });

  return {
    key: p.policyType,       // "hus"
    label: p.label,          // "Hus"
    annualSavings: annual,
    monthlySavings: monthly,
    tenYearSavings: tenYear,
    points,
  };
});

const totalAnnual = series.reduce((sum, s) => sum + s.annualSavings, 0);
const totalTenYear = series.reduce((sum, s) => sum + s.tenYearSavings, 0);

view.savingsOverTime = {
  totalAnnualSavings: totalAnnual,
  totalTenYearSavings: totalTenYear,
  series,
};
```

### How to wire this into the Subframe AreaChart

In your `ComparisonSavingsSection` component:

1. Accept the **whole** `SavingsOverTimeView` and an `activePolicyKey`:

```ts
interface ComparisonSavingsSectionProps {
  savings: SavingsOverTimeView;
  activePolicyKey: string | "all"; // "samlet", "indbo", "hus", etc.
}
```

2. Decide which series to show:

```ts
const visibleSeries =
  activePolicyKey === "all"
    ? savings.series
    : savings.series.filter((s) => s.key === activePolicyKey);
```

3. Build `AreaChart` `categories` and `data` dynamically:

```ts
const categories = visibleSeries.map((s) => s.label); // ["Indbo", "Hus", "Ulykke"]

const data = Array.from({ length: 120 }, (_, i) => {
  const month = i + 1;
  const entry: any = { Måned: `Måned ${month}` };

  visibleSeries.forEach((s) => {
    const point = s.points[i];
    entry[s.label] = point?.cumulative ?? 0;
  });

  return entry;
});
```

Then use the Subframe chart:

```tsx
<AreaChart
  className="mobile:h-64 mobile:flex-none"
  categories={categories}
  data={data}
  index="Måned"
/>
```

4. Cards at the bottom:

* **Samlet** (activePolicyKey === "all"):

  * Månedlig besparelse → `totalAnnualSavings / 12`
  * Total efter 12 måneder → `totalAnnualSavings`
  * Forventet efter 10 år → `totalTenYearSavings`
* **Single policy tab**: use that policy’s `monthlySavings`, `annualSavings`, `tenYearSavings`.

That gives you exactly what you described:

* All policy types in the chart simultaneously
* Click the existing top tabs (Samlet / Indbo / Hus / Ulykke…) to “focus” the chart + cards on one line vs all
* Fully dynamic: if the backend outputs more/less policies, chart adapts automatically.
