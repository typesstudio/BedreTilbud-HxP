## 3. Fix Phase 4: Comparison JSON per policy

At this point the likely situation is:

* For each policy pair you **do** have:

  * current + offer premiums
  * some health-check text
* But the **ComparisonAgent** and/or orchestrator:

  * Only calculates totals in `summary`,
  * And never fills `annualSavings`, `percentageSavings`, `coverageRows` for each policy.

Given what you want, I’d do this:

### 3.1. Move savings calculation into code, not AI

In `comparisonOrchestrator.ts`, when you build the `policyComparisons` array (before calling the AI):

```ts
const policyComparisons = matchedPairs.map(pair => {
  const current = pair.current;
  const offer = pair.offer;

  const currentPremium = current.annualPremium ?? current.healthCheck?.annualPremium;
  const offerPremium   = offer.annualPremium ?? offer.healthCheck?.annualPremium;

  const annualSavings = currentPremium != null && offerPremium != null
    ? currentPremium - offerPremium
    : null;

  const percentageSavings = annualSavings != null && currentPremium
    ? (annualSavings / currentPremium) * 100
    : null;

  return {
    policyType: current.policyType,
    currentAnnualPremium: currentPremium,
    offerAnnualPremium: offerPremium,
    annualSavings,
    percentageSavings,
    coverageRows: [],       // fill below or via AI
    // plus ids, raw healthCheck snippets, etc.
  };
});
```

Then pass **this** `policyComparisons` into the AI with a hard rule:

> “You MUST NOT change, remove or add items in `policyComparisons`. You may only fill in `highlights`, `narratives` and `coverageRows` for each existing item.”

That way:

* Your per-policy cards can *always* trust `annualSavings` and `percentageSavings`.
* The combined totals can either be taken from `summary` or computed by summing `policyComparisons[].annualSavings`.

### 3.2. Populate coverageRows deterministically where possible

Start simple:

* Use the health check result for each policy:

  ```ts
  const currentCoverages = current.healthCheck?.coverages ?? [];
  const offerCoverages   = offer.healthCheck?.coverages ?? [];

  // Build a union by coverage name
  const allCoverageNames = uniq([
    ...currentCoverages.map(c => c.name),
    ...offerCoverages.map(c => c.name),
  ]);

  const coverageRows = allCoverageNames.map(name => {
    const cur = currentCoverages.find(c => c.name === name);
    const off = offerCoverages.find(c => c.name === name);

    return {
      name,
      currentValue: cur?.amount ?? cur?.included ?? null,
      offerValue: off?.amount ?? off?.included ?? null,
    };
  });
  ```

* Attach `coverageRows` directly in code; let the AI only rewrite the **titles/labels** or add human-readable highlight sentences.

That will make the “Detaljeret sammenligning” table non-empty.

If the health checks are weak for indbo/ulykke right now, you’ll see that quickly – then you know to improve that prompt separately.
