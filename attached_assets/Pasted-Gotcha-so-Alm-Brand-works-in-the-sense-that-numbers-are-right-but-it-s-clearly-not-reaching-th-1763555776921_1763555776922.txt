## Plan: Make the comparison actually “rich” like your Tryg mock

### 1. Upgrade coverage comparison to use *all* coverages, not just 1

Right now, per your report, `coverageComparison.rows` has exactly one row per policy (Brand, Tyveri, Invaliditet).

You want the **full table**. To get that:

1. **Find the richest coverage source** in your data model:

   * Either:

     * `offer_snapshots.coverageDetails` (from OCR → structured coverages), or
     * `health_checks.result_json.coverages` (if you’re already storing a list there).

2. In `comparisonOrchestrator` when you build `policyComparisons`:

   ```ts
   const currentCoverages = current.coverageDetails ?? current.healthCheck?.coverages ?? [];
   const offerCoverages   = offer.coverageDetails   ?? offer.healthCheck?.coverages   ?? [];

   const coverageNames = Array.from(new Set([
     ...currentCoverages.map(c => c.name?.trim()),
     ...offerCoverages.map(c => c.name?.trim()),
   ].filter(Boolean)));

   const rows = coverageNames.map(name => {
     const cur = currentCoverages.find(c => c.name === name);
     const off = offerCoverages.find(c => c.name === name);

     return {
       coverage: name,
       description: cur?.description || off?.description || null,
       current: {
         value: cur ? (cur.included ? 'inkluderet' : 'ikke inkluderet') : 'ikke nævnt',
         limit: cur?.amountText ?? cur?.limit ?? null,
         selvrisiko: cur?.deductibleText ?? null,
       },
       offer: {
         value: off ? (off.included ? 'inkluderet' : 'ikke inkluderet') : 'ikke nævnt',
         limit: off?.amountText ?? off?.limit ?? null,
         selvrisiko: off?.deductibleText ?? null,
       },
     };
   });
   ```

3. Plug `rows` into `coverageComparison.rows`.

4. Optionally limit to, say, the first 20 rows in the UI to avoid insane tables.

👉 This change alone will turn your “1 row per tab” into a **rich coverage table** like the Tryg mock.

**Implementation steps:**

   const annualSavings = overall.totalCurrentAnnualPremium - overall.totalOfferAnnualPremium;

   const tenYearSavings = annualSavings * 10;

     month: i + 1,
     savings: monthlySavings * (i + 1),
